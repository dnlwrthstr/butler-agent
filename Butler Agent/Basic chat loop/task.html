Description

In this stage, you will create a basic conversation system with an LLM (Large Language Model). This involves setting up the API connection and implementing a simple back-and-forth conversation without any tools, focusing only on text conversation.

Your first task is to initialize the OpenAI-compatible API client. You'll use the openai Python library to connect to your LLM provider. Store the API credentials (API key and base URL) securely in a .env file and load them using the dotenv library.

Note: This project involves the use of private keys (API keys) and .env files. Make sure you do not expose your keys by hardcoding them directly into the solution. Instead, always reference them securely from your .env file using environment variables:

LITELLM_API_KEY=your_api_key_here
LITELLM_BASE_URL=your_base_url_here

If you're using OpenAI API directly, your should name your environmental variables accordingly

OPENAI_API_KEY=your_api_key_here

BASE_URL is not required if using OPENAI directly.

After initializing the API client, you'll set up a basic conversation. This involves:

  1. Creating a system prompt that defines the assistant's behavior and role;

  2. Building a conversation context (list of messages);

  3. Sending the context to the API;

  4. Receiving and displaying the assistant's response.

At this stage, you're working with the THINK part of the THINK-ACT-OBSERVE loop. The agent can only generate text responses; it cannot use any tools yet.

The conversation flow looks like this:

User → LLM (THINK) → Text Response

For this stage, create a simple interaction where the user asks: "What's the weather like today?" and the assistant will respond with a generic answer (no real weather data yet, since we haven't implemented tools).

Objectives

In this stage, you should:

  1. Set up the OpenAI client with proper authentication using environment variables.

  2. Define a system prompt that instructs the assistant to be helpful.

  3. Create a conversation context with a user message.

  4. Call the API using client.responses.create() method.

  5. Extract and display the assistant's response from response.output.

  6. Handle only the item.type == 'message' branch (no tools yet).

Examples

Example 1:

[USER]: Hey, how are you?
[ASSISTANT]: I'm here and ready to help you! What do you need assistance with today?

Example 2:

[USER]: Hey, how are you?
[ASSISTANT]: I currently can't check the real-time weather, but you can find current weather information through a weather app or website.
Key concepts

  • Context: A list of messages that represents the conversation history.

  • System prompt: Instructions that define how the assistant should behave.

  • Response object: Contains the LLM's output, which can include text messages or tool calls (in later stages).

  • Message type: In this stage, we only handle type == 'message', which represents text responses.

Tips

  • Keep your .env file in the same directory as your script.

  • The client.responses.create() method requires model, instructions, and input parameters.

  • Find the response in response.output, which is a list of output items.

  • Each output item has a type attribute: for this stage, check for type == 'message'.
